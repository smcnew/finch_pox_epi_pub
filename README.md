# Diverse environmental and host-specific drivers of avian pox dynamics in the Galápagos Islands.
## Scripts and data for McNew et al. 2026

Repo includes:

- input_data/ : raw data files\
- formatted_data/ : processed data used in analyses\
- scripts/ : scripts for analyzing data
- output\* / : output figures and tables

Note: map_files/ is an empty directory that will be populated by when running script 0_map_of_study.R. The associated spatial files in this directory are not included because of issues pushing large files to Github.
